_build_process

Document Ingestion & Preprocessing

Built custom PDF/DOCX parsers that handle complex legal formatting — tables, footnotes, multi-column layouts. Documents are cleaned, deduplicated, and split into semantic chunks using recursive character splitting with overlap.

Embedding & Vector Indexing

Used OpenAI's text-embedding-3-large model to create 3072-dimensional vectors. Indexed in Pinecone with metadata filtering for document type, jurisdiction, and date — enabling hybrid search.

LLaMA-3 Fine-Tuning

Fine-tuned LLaMA-3-8B on 2,000 expert-annotated legal Q&A pairs using QLoRA (4-bit quantization). Trained on 2x A100 GPUs for 3 epochs with a custom loss function that penalizes hallucinated citations.

API Deployment & Monitoring

Wrapped in FastAPI with async request handling, response caching in Redis, and a Streamlit dashboard for non-technical users. Integrated LangSmith for tracing every retrieval and generation step.
