System Architecture

PDF/DOCX Input → Chunker → Embedder → Pinecone Vector DB. User Query → Semantic Search → Top-K Context → Fine-tuned LLaMA-3 Generator → Answer with Citations.

Build Process

  • Document Ingestion & Preprocessing: Built custom PDF/DOCX parsers that handle complex legal formatting — tables, footnotes, multi-column layouts. Documents are cleaned, deduplicated, and split into semantic chunks using recursive character splitting with overlap.
  • Embedding & Vector Indexing: Used OpenAI's text-embedding-3-large model to create 3072-dimensional vectors. Indexed in Pinecone with metadata filtering for document type, jurisdiction, and date — enabling hybrid search.
  • LLaMA-3 Fine-Tuning: Fine-tuned LLaMA-3-8B on 2,000 expert-annotated legal Q&A pairs using QLoRA (4-bit quantization). Trained on 2x A100 GPUs for 3 epochs with a custom loss function that penalizes hallucinated citations.
  • API Deployment & Monitoring: Wrapped in FastAPI with async request handling, response caching in Redis, and a Streamlit dashboard for non-technical users. Integrated LangSmith for tracing every retrieval and generation step.

Key Challenges

  • Edge Constraints: Jetson Nano has only 4GB shared memory. Had to quantize the YOLOv8-m model from FP32 to INT8 using TensorRT post-training quantization, losing only 0.8% mAP while gaining 4x speedup.
  • Domain Shift: Factory lighting changes throughout the day. Solved with test-time augmentation — running inference on 4 augmented versions of each frame and averaging predictions for robustness.
  • Data Imbalance: Defects are rare (~2% of samples). Used focal loss with gamma=2.0 and oversampled defect patches via CutMix to balance the training distribution without losing normal-class representation.
  • Real-Time Alerting: Built a C++ inference server that communicates with PLC controllers via Modbus TCP. When a defect is detected, the conveyor belt stops within 200ms — before the part reaches the next station.

Project 05 — Audio AI

How It Works

A 3-second reference audio clip is passed through XTTS v2's speaker encoder to extract a speaker embedding vector. This embedding conditions the text-to-speech decoder to synthesize speech in the reference speaker's voice. The system supports 17 languages and can generate emotive speech with configurable emotion parameters (neutral, happy, sad, angry).

Fine-Tuning Approach

The base XTTS v2 model was fine-tuned on 50 audio files (~30 minutes) per target speaker using the Coqui TTS training pipeline. Learning rate: 1e-5 with cosine annealing. Training on a single A100 GPU took approximately 2 hours per speaker. A Gradio web interface was built for non-technical users to upload a reference clip, type text, and download the cloned audio.

Use Cases

  • Accessibility: Generating speech for individuals who have lost their voice
  • Content Creation: Audiobook narration in a consistent voice across chapters
  • Education: Creating personalized learning materials with familiar voices
Project 06 — Medical AI

Medical Image Segmentation

U-Net++ based brain tumor segmentation from 3D MRI scans — achieving radiologist-level performance on the BRATS2023 dataset with novel attention-gated skip connections.

Data Preparation

  • BRATS2023: 8,500 training volumes across 4 MRI modalities (T1, T1ce, T2, FLAIR)
  • Intensity normalization using z-score per modality
  • Random crops: 128x128x128 with 4-class labels (background + 3 tumor regions: enhancing tumor, tumor core, whole tumor)
  • Augmentations: elastic deformation, rotation, Gaussian noise, brightness shift

Training Configuration

  • Optimizer: AdamW (lr=1e-4, weight decay=1e-5)
  • Loss: Combined Dice + Focal loss (alpha=0.5 each) to handle severe class imbalance
  • LR Scheduler: Cosine annealing with warm restarts
  • Hardware: 4x A100 80GB GPUs, mixed precision (AMP), 350 epochs

Model Architecture

Based on U-Net++ with attention-gated skip connections. The attention gate takes the gating signal from the decoder and the skip connection from the encoder, computes attention coefficients via a sigmoid activation, and multiplies the skip features to suppress irrelevant regions and focus on tumor boundaries. Built using MONAI's UNet implementation with custom attention modules. Input: 4 channels (MRI modalities), Output: 4 channels (background + 3 tumor regions), Channel depths: 32-64-128-256-512 with stride-2 downsampling.

Clinical Integration

Segmentation masks are exported as NIfTI files compatible with 3D Slicer for radiologist review. Volume metrics (tumor volume in cm³) are automatically computed and formatted into a structured report. The model runs as a REST API using FastAPI, integrated into the hospital's PACS system for on-demand analysis.
