key challenges

01 // Edge Constraints

Jetson Nano has only 4GB shared memory. Had to quantize the YOLOv8-m model from FP32 to INT8 using TensorRT post-training quantization, losing only 0.8% mAP while gaining 4x speedup.

02 // Domain Shift

Factory lighting changes throughout the day. Solved with test-time augmentation — running inference on 4 augmented versions of each frame and averaging predictions for robustness.

03 // Data Imbalance

Defects are rare (~2% of samples). Used focal loss with γ=2.0 and oversampled defect patches via CutMix to balance the training distribution without losing normal-class representation.

04 // Real-Time Alerting

Built a C++ inference server that communicates with PLC controllers via Modbus TCP. When a defect is detected, the conveyor belt stops within 200ms — before the part reaches the next station.
